# Faculdad# Projeto Inclusão Digital

Projeto desenvolvido para a disciplina de Atividade Extensionista do curso de Análise e Desenvolvimento de Sistemas.

## Objetivo

Promover a inclusão digital através de uma aplicação web simples contendo orientações sobre tecnologia e segurança na internet.

## Tecnologias Utilizadas

- Python
- FastAPI
- HTML
- CSS

## Como Executar

Instalar dependências:

pip install -r requirements.txt

Executar:

uvicorn main:app --reload

Acessar:

http://127.0.0.1:8000

Documentação:

http://127.0.0.1:8000/docs
